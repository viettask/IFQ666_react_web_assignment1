# IFQ666 React Web Assignment 1

This repository is for the IFQ666 React Web Assignment 1. It is a basic React application created as part of the assignment.

## Project Setup

To run this project locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/viettask/IFQ666_react_web_assignment1.git
   ```

2. Navigate into the project directory:
   ```bash
   cd IFQ666_react_web_assignment1
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Run the project:
   ```bash
   npm start
   ```
